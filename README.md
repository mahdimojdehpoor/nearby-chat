نزدیک‌چت (Nearby Chat)
یک برنامه‌ی وب ساده با Flask برای پیدا کردن و چت‌کردن با افراد نزدیک به شما، بر اساس موقعیت مکانی مرورگر (GPS).
امکانات
ثبت‌نام و ورود کاربران (رمز عبور هش‌شده با Werkzeug)
دریافت موقعیت مکانی از مرورگر (Geolocation API) و ذخیره در دیتابیس
لیست افراد نزدیک بر اساس فاصله (فرمول Haversine) با شعاع قابل تنظیم
وضعیت آنلاین/آفلاین
چت خصوصی یک‌به‌یک بین دو کاربر (به‌روزرسانی خودکار هر ۲ ثانیه با AJAX polling — بدون نیاز به WebSocket)
دیتابیس SQLite، بدون نیاز به نصب سرور جداگانه
اجرا روی سیستم خودتان
Bash
سپس در مرورگر بروید به: http://127.0.0.1:5000
نکته: چون از GPS مرورگر استفاده می‌شود، مرورگر از شما اجازه‌ی دسترسی به موقعیت مکانی می‌خواهد. روی http://localhost این کار بدون مشکل انجام می‌شود؛ برای دامنه‌ی واقعی حتماً باید HTTPS فعال باشد.
ساختار پروژه
Code
آپلود روی گیت‌هاب
Bash
(به‌جای USERNAME/REPO_NAME آدرس ریپوی خودتان را در گیت‌هاب بگذارید — اول باید یک ریپوی خالی در گیت‌هاب بسازید.)
نکات امنیتی برای استفاده‌ی واقعی (Production)
این نسخه یک نمونه‌ی آموزشی/پایه است. قبل از انتشار عمومی حتماً موارد زیر را اضافه کنید:
تغییر app.secret_key به یک مقدار تصادفی و امن (و نگه‌داشتن آن در متغیر محیطی)
استفاده از HTTPS
محدودسازی نرخ درخواست‌ها (Rate limiting) برای جلوگیری از اسپم
اعتبارسنجی و پاک‌سازی بیشتر ورودی‌ها
به‌جای SQLite ساده، برای مقیاس بزرگ‌تر از PostgreSQL استفاده کنید
افزودن گزارش/بلاک‌کردن کاربران و مدیریت محتوا، بخصوص چون افراد غریبه با هم در ارتباط قرار می‌گیرند
برای چت واقعاً بلادرنگ (real-time) به‌جای polling، می‌توانید بعداً flask-socketio یا Flask-SSE اضافه کنید
ایده‌های توسعه‌ی بعدی
آپلود عکس پروفایل
فیلتر بر اساس علایق مشترک
اعلان (Push Notification) هنگام پیام جدید
نقشه‌ی تعاملی (Leaflet.js) برای نمایش افراد نزدیک روی نقشه
